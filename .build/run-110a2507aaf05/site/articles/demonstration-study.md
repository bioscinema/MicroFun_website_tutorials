# Demonstration studies

## Choose the PICRUSt2 output type

- [Demonstration Study
  (Stratified)](https://bioscinema.github.io/MicroFun_website_tutorials/articles/demonstration-stratified.md)
  presents the complete visualization set for both taxon-centered and
  function-centered results.
- [Demonstration Study
  (Standard)](https://bioscinema.github.io/MicroFun_website_tutorials/articles/demonstration-standard.md)
  compares KO and KEGG community profiles using PCA, heatmaps and group
  abundance summaries.
