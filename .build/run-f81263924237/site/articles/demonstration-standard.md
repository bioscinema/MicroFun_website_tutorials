# Demonstration Study (Standard)

## Standard PICRUSt2 demonstration

The analysis and figures for this demonstration are being prepared.

For input formats and available functions, see the [standard PICRUSt2
workflow](https://bioscinema.github.io/MicroFun_website_tutorials/articles/standard-pipeline.md)
and [Community-level
visualizations](https://bioscinema.github.io/MicroFun_website_tutorials/articles/sample-level-plots.md).

## Data for this workflow

Standard PICRUSt2 output contains a function-by-sample matrix, with one
predicted community-level abundance per function in each sample.
Matching sample metadata identifies the groups to compare. Unlike a
stratified contribution table, this input pools the ASV contributions
within each sample.

This page will describe the study cohort and display the completed
analyses when those results are available.
