# Metadata for ggpicrust2 Demonstration

This is a demonstration dataset from the ggpicrust2 package. It provides
the metadata required for the demonstration functions in the package.
The dataset includes environmental information for each sample.

## Usage

``` r
metadata
```

## Format

A tibble with each row representing metadata for a sample.

- Sample1:

  Metadata for Sample1, including Environment

- Sample2:

  Metadata for Sample2, including Environment

- ...:

  ...

## Source

ggpicrust2 package demonstration.
