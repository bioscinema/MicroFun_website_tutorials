# Package index

## Taxonomy to function

- [`tax2fun_box()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/tax2fun_box.md)
  : Plot Functional Abundance Boxplots for Driving Taxa
- [`tax2fun_chord()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/tax2fun_chord.md)
  [`print(`*`<microfun_chord>`*`)`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/tax2fun_chord.md)
  [`plot(`*`<microfun_chord>`*`)`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/tax2fun_chord.md)
  : Chord diagram of taxon-resolved functional contributions
- [`tax2fun_dendro()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/tax2fun_dendro.md)
  : Dendrogram of top stratified functions per taxon (circular)
- [`tax2fun_logfc()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/tax2fun_logfc.md)
  : Plot signed logFC pathways for each taxon (list of plots)
- [`tax2fun_sankey()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/tax2fun_sankey.md)
  : Sankey diagram of taxon -\> pathway-class contributions (PICRUSt2
  stratified)

## Function to taxonomy

- [`fun2tax_box()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/fun2tax_box.md)
  : Plot function-to-taxon contributions as grouped boxplots
- [`fun2tax_chord()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/fun2tax_chord.md)
  : Chord diagram from function-oriented differential results
- [`fun2tax_dendro()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/fun2tax_dendro.md)
  : Dendrogram of top differential taxa per function
- [`fun2tax_logfc()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/fun2tax_logfc.md)
  : Plot signed taxon effects for each function
- [`fun2tax_sankey()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/fun2tax_sankey.md)
  : Sankey diagram: functions (KO/EC/MetaCyc) to taxa/features

## Pathway analysis and visualization

- [`pathway_annotation()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/pathway_annotation.md)
  : Pathway information annotation
- [`pathway_daa()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/pathway_daa.md)
  : Differential Abundance Analysis for Predicted Functional Pathways
- [`pathway_errorbar`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/pathway_errorbar.md)
  : The function pathway_errorbar() is used to visualize the results of
  functional pathway differential abundance analysis as error bar plots.
- [`pathway_heatmap`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/pathway_heatmap.md)
  : Create pathway heatmap
- [`pathway_pca()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/pathway_pca.md)
  : Perform Principal Component Analysis (PCA) on functional pathway
  abundance data
- [`pathway_sdaa()`](https://bioscinema.github.io/MicroFun_website_tutorials/reference/pathway_sdaa.md)
  : Stratified pathway-level DAA workflow for PICRUSt2 outputs
